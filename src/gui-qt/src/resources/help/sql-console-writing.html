What a query gives back

a condition : port = 80 AND host LIKE '%.fr' — the shortest form, and the one to reach for. It becomes the selection
SELECT rowid … : the same, said in full, for what a condition cannot express: subqueries, aggregates, WITH
anything else : a GROUP BY, a COUNT — shown in a panel beside the views, leaving the selection alone. Two columns of value and count are drawn like the distinct-values listing
an error : appears under the console, and names what would have worked
