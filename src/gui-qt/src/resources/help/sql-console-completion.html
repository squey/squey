What Ctrl+Space offers, under a heading per kind

after FROM : the scopes, the layers of this view by name, and the other sources of the project — each written the way that reaches it
after WHERE : the columns and the type each one holds, then the conversions that apply to them, then the columns of the sources a join can reach
two letters in : DuckDB's own functions join the list, with what each one is for. They wait for those two letters because there are hundreds, and they would otherwise bury the columns
elsewhere : the keywords, grouped by what they are for: clauses, operators, aggregates, conditions
layer('name') : picking it offers the layers straight away. Typing between the quotes completes a name there too, spaces and all
source := 'name' : the same between those quotes: every source a query can name, this one included
upper case : picks between two that begin alike — SELE reaches the keyword, sele the scope. Both stay on offer either way
click a column : lists every other column, with what each one holds. Picking one replaces the name that was clicked
a keyword expecting more : opens the next list by itself, so a query is written by picking rather than by recalling what comes next
