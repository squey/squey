Addresses and dates

An address, a MAC and a date are each stored as the number whose order is their own — which is what makes ORDER BY right. A query therefore reads 3232235777 where the listing shows 192.168.1.10.
ipv4('…') : to compare a column against, and the fast direction
ipv4_text(col) : to read one. It builds a string per row, so keep it out of a WHERE
mac_address(…) : the same pair for a MAC, with mac_address_text(col)
to_timestamp(col) : reads a date, stored as an epoch in seconds
which is which : the completion says, beside each column name, what it really holds
