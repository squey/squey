Addresses and dates

An address, a MAC and a date are each stored as the number whose order is their own — which is what makes ORDER BY right. A query therefore reads 3232235777 where the listing shows 192.168.1.10.
ipv4('…') : an address, to compare a column against — and the fast direction, since it leaves the comparison on the stored number
ipv4_text(column) : the address a column holds, as text. It builds a string per row, so keep it out of a WHERE
mac_address('…') : an address, to compare a column against — with mac_address_text(column) to read one
to_timestamp(column) : the instant a column holds, stored as an epoch in seconds. A date in milliseconds reads with epoch_ms(column)
