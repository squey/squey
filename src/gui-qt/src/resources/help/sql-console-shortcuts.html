Keys

Enter : run the query
Ctrl+Enter : break the line, as does Shift+Enter
Ctrl+Space : offers what fits where the cursor is: tables after FROM, columns after WHERE, keywords elsewhere
click a column : lists every other column, with what each one holds. Picking one replaces the name that was clicked
Escape : closes this page, or the completion list
? : this page, as does F1 or the button in the title bar
