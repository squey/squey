All of the above, in one query

SELECT rowid FROM layers WHERE src = ipv4('192.168.1.10') AND to_timestamp("start-time") >= '2024-01-01' AND host IN (SELECT host FROM layer('All events') GROUP BY host HAVING COUNT(DISTINCT "user-agent") = 1)
SELECT rowid : the row index alone, which is what turns a result into the selection. Project anything else and the result is shown in a panel instead
FROM layers : the rows to read — here everything the layer stack lets through
ipv4('…') : the address as text. Converting the value rather than the column is what keeps the comparison on the stored number, and fast
to_timestamp(…) : a date is stored as an epoch; this reads it back as an instant
"start-time" : double quotes name a column — needed here for the dash. Single quotes hold a string, which is the reverse of most languages
IN (SELECT …) : a query may read a second table, here every row, to work out which hosts qualify before narrowing the first
