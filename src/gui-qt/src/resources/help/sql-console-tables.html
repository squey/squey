Which rows a query reads

selection : what is selected right now. A condition written on its own reads this, so asking narrows what you already have
layers : everything the layer stack lets through — what the listing shows
layer('name') : one layer, by the name it carries in the layer stack
layer('All events') : every row of the source: the base layer cannot be removed, so this is how a query reaches past everything else
(text := true) : on any of the three — every column as it was written. The only way to see a cell the format could not read, which is NULL otherwise
