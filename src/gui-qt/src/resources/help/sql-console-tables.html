Which rows a query reads

selection : the currently selected rows — what the listing shows. A condition written on its own reads this, so asking narrows what you already have
layers : every row the layer stack lets through
layer('name') : one layer, by the name it carries in the layer stack. The base layer — the one that cannot be removed, called All events until you rename it — holds every row of the source, so naming it is how a query reaches past everything else
(text := true) : every column as it was written, on any of the three. The only way to see a cell the format could not read, which is NULL otherwise
source.selection : the selection of another source, under that source's own name — which is how a query joins across sources
(source := 'name') : the same reach, spelt out. Two sources may carry one name, and source_position := 1 then picks the second of them
sources : every source a query can name, with its position, its size and which one this console sits on
